# Murugesh Maligai – Grocery E-Commerce Website

A responsive grocery e-commerce website developed for a local grocery business based on real-world business requirements.

## Features

- Product categories and filtering
- Product search
- Shopping cart
- Quantity management
- WhatsApp ordering
- Responsive design
- Product catalog
- Mobile-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
